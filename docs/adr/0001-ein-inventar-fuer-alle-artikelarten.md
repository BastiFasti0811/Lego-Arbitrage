# Ein Inventar für alle Artikelarten

Das bestehende Lego-Inventar wird generalisiert (`item_type` LEGO/GENERIC, Set-Nummer optional), statt für Nicht-Lego-Artikel ein separates Verkaufs-Modul zu bauen. Eine Foto-, Listing- und Anpassungs-Mechanik für alles; Lego behält seine speziellere Preisquelle (Marktdaten-Pipeline), Sonstiges nutzt KI-Schätzung plus eBay-Verkaufspreise. Die Alternative „separates Modul" wurde verworfen, weil sie Foto-Verwaltung, Listing-Status und Anpassungs-Trigger dupliziert hätte — die Lego-Artikel brauchen all das ebenfalls. (Entschieden 2026-08-29.)
